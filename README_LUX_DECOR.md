# LUX DECOR ERP

Cópia independente do ERP Home Interiores v2.18.4, preservando estrutura e funcionalidades.

- Identidade Lux Decor e ícones próprios.
- Armazenamento local segregado (`luxdecor-` / `luxdecorerp-`).
- Cadastros iniciais de produtos, clientes, fornecedores e movimentos vazios.
- Não incorpora dados de negócios da Home Interiores.
- Login local de demonstração herdado do sistema base: **as credenciais são estáticas no código e não são seguras para produção**. Substituir por autenticação segura antes de uso com dados reais.

Executar: `npm install`, `npm run build`, `npm run dev`.
